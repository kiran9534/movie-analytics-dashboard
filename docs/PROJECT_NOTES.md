# Movie Analytics — Project Notes

## Workbook structure

The supplied workbook contains:
- a main movie dataset
- a data-preparation/analysis sheet
- Pivot Table analysis
- chart/dashboard content

## Main analysis dimensions

The dashboard focuses on:
- movie subject/genre
- movie era
- awards
- popularity
- runtime

## Analysis approach

I used Pivot Tables to aggregate movie counts and average values, then used charts and dashboard controls to make comparisons easier for a user.
