# Movie Analytics Dashboard

## Overview

This Excel project explores a movie dataset using Pivot Tables, charts, and an interactive dashboard. The goal was to understand how movie genre, era, runtime, popularity, awards, and people involved in the movies vary across the dataset.

## Business questions

- Which genres have the most movies?
- How does average movie length change across eras?
- How does popularity vary across eras?
- How do awards relate to movie characteristics?
- Which categories or groups stand out in the dataset?

## Dataset

The main dataset contains 1,662 movie records with fields such as:
- year
- movie length
- title
- subject/genre
- actor
- actress
- director
- popularity
- awards
- era

## Tools

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Dashboard filters/slicers

## Key findings

- Drama is the largest genre by volume in the analysis.
- The dashboard compares average movie runtime and popularity across classic, golden, and modern eras.
- The workbook also supports analysis by subject, era, and awards.
